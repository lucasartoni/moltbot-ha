## [1.0.0] - 2026-01-28

### Added

- Initial release of Moltbot Home Assistant Add-on
- Support for Anthropic and OpenAI models
- Telegram integration with group allowlisting
- Discord integration with server allowlisting
- Slack integration with Socket Mode
- WhatsApp integration (experimental)
- Configurable sandbox mode for security
- WebSocket control plane on port 18789
- Persistent configuration storage
