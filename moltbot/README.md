# Moltbot Add-on for Home Assistant

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Your personal AI assistant running on Home Assistant. Connect to Telegram, WhatsApp, Discord, Slack, and more.

## About

Moltbot is a self-hosted AI assistant platform that:

- Connects to multiple messaging platforms
- Uses Claude or GPT models for intelligent responses
- Keeps your data local and private
- Runs sandboxed for security

## Installation

1. Add this repository to your Home Assistant add-on store
2. Install the Moltbot add-on
3. Configure your API keys and messaging platforms
4. Start the add-on

## Configuration

See the [documentation](DOCS.md) for full configuration options.

### Quick Start

1. Get an API key from [Anthropic](https://console.anthropic.com/) or [OpenAI](https://platform.openai.com/)
2. Create a Telegram bot with [@BotFather](https://t.me/BotFather)
3. Configure the add-on with your keys
4. Start chatting with your AI assistant!
