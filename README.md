# Moltbot Add-ons Repository for Home Assistant

This repository contains Home Assistant add-ons for running Moltbot, your personal AI assistant.

## Add-ons

### [Moltbot](./moltbot)

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Your personal AI assistant. Connect to Telegram, WhatsApp, Discord, Slack, and more messaging platforms while keeping full control of your data.

## Installation

1. Navigate to **Settings** > **Add-ons** in Home Assistant
2. Click the menu icon (three dots) in the top right
3. Select **Repositories**
4. Add this repository URL: `https://github.com/lucasartoni/moltbot-ha`
5. Click **Add**
6. Find "Moltbot" in the add-on store and click **Install**
